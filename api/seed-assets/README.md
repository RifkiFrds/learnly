# Aset demo Learnly

Dibuat oleh `npm run demo:assets` (src/scripts/generate-demo-assets.ts) dari data di `src/scripts/demo/data.ts`.
Jangan diedit manual — ubah datanya lalu jalankan ulang generator.

- `covers/` sampul kursus tipografis (SVG, token warna design system)
- `documents/` ijazah & sertifikat tutor dummy (PDF, watermark "DUMMY / CONTOH")
- `receipts/` struk transfer dummy bertuliskan DEMO, nominal sesuai tagihan
- `qris/` QR contoh berisi teks "LEARNLY-DEMO" berlabel "QRIS CONTOH" (bukan QRIS asli)
- `lessons/` materi PDF lesson
- `submissions/` contoh file tugas siswa

Tidak ada foto orang, wajah hasil AI, maupun aset berhak cipta. Tidak ada video (ffmpeg tidak tersedia saat pembuatan).
